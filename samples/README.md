# 示例数据 (samples)

> 这个目录用于存放示例照片、示例输出、示例配置等。

## 用途

1. **演示用照片** — 评委 / 用户可以快速试,不用自己拍
2. **回归测试样本** — 团队后续跑批量测试
3. **UI 截图样本** — README / 文档里贴的图都从这里出

## 当前状态

MVP 0.1.0 阶段,暂不放真实照片(隐私 + 体积)。

## 如何放示例

```bash
# 把照片放到 samples/ 下的子目录,前端选文件夹时能选到
samples/
├── 我的婚礼_2024/
│   ├── IMG_001.ARW
│   ├── IMG_002.JPG
│   └── ...
└── 街拍_胶片/
    └── roll01/
```

## 注意事项

- 真实人脸 / 车牌记得打码
- 大文件建议用 `.gitignore` 排除
- 占体积 < 100 MB / 目录
